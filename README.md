# Anup Aryal Portfolio Starter

This is a static portfolio website built with plain HTML, CSS, and JavaScript.

## Files
- index.html
- style.css
- script.js
- assets/Anup_Aryal_CV.pdf  <-- add your own CV file here

## Before publishing
1. Replace the LinkedIn placeholder URL in index.html.
2. Add your CV as `assets/Anup_Aryal_CV.pdf`.
3. Add your teaching demo URL in `script.js`.
4. Review the engineering and SAT text.
5. Replace the Problem Studio placeholders with selected portfolio questions later.

## Open locally
Double-click index.html, or use the VS Code Live Server extension.

## Publish
Upload all files to a GitHub repository named:
YOUR-GITHUB-USERNAME.github.io

Then enable GitHub Pages from:
Settings > Pages > Deploy from a branch > main > /(root)
