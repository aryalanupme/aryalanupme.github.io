SAT PRACTICE FILE SETUP
=======================

The website code is already configured for stable PDF paths. Before publishing the Practice Library, copy FINAL PDF files into these folders using the exact filenames below.

IMPORTANT
- The website intentionally does NOT display a permanent question count for any practice set.
- You can later replace a PDF with an expanded/revised version using the SAME filename. No HTML change is needed.
- Keep editable DOCX files outside the public GitHub Pages site unless you intentionally want them public.
- Geometry/triangle/circle PDFs can be replaced later after diagrams are improved. Keep the same filenames.
